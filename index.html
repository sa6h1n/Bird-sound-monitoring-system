Project Overview

Real-World Application

In real-world deployments, this system can be integrated with IoT devices such as Raspberry Pi or ESP32 equipped with microphones and placed in natural habitats. These devices continuously capture environmental audio and transmit it for centralized analysis, enabling long-term wildlife and ecosystem monitoring.

System Implementation

This web application demonstrates the same concept using a browser-based microphone. Audio is analyzed using an AI bird sound classification model inspired by the BirdNET deep learning framework. Only the most confident species per recording is stored in a cloud-hosted PostgreSQL database (Supabase) and used to visualize detection history, biodiversity trends, and ecosystem health.

AI Model: BirdNET-inspired CNN  •  Backend: Supabase (PostgreSQL)  •  Frontend: Web Audio API + Chart.js
